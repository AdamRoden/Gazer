# Speech composer

Drawer **Speak** (`compose.open`) opens `compose.xml`. This is an internal phrase, not OS typing.

- Type on the composer keyboard into a buffer. A row above the phrase offers the next word or a spelling fix. Dwell a suggestion to insert it. Word chips: first dwell jumps the caret; later dwells delete the word (`<Phase>`). Past 12 words, the first and last chips page the row backward and forward by 5 words.
- Word predictions use a sentence-sized model shipped with Gazer (`resources/predict/model.bin`). A usage-ranked dictionary completes words that are not in the sample phrases. Words you accept are remembered under `%AppData%\Gazer\predict-user.bin`. Turn the row off under Settings → **Speak**.
- **Speak** synthesizes the buffer. Engine is **ElevenLabs v4 Turbo** when that model, a DPAPI-stored API key, and a voice id are set; otherwise **Windows SAPI**. One untagged phrase at speed 1 and pitch 1 plays as the audio arrives. A standing style or an inline `[tag]` is repeated on each breath (split at punctuation, keeping numbers, times, and web addresses whole). Speed and pitch are applied on the PC after the audio arrives, and that clip is what History replays. Three Eleven failures latch SAPI until model, voice, or key changes.
- XML `<Speak value="Hello"/>` is always Windows SAPI (a canned cell utterance). Composer **Speak** is the command `compose.speak` and uses Settings → **Speak** (SAPI or v4 Turbo).
- **Soundboard**: pin the spoken clip onto topic cells; replay without re-synthesis. Store: `%AppData%\Gazer\` (`boards.json`, `clips/`).
- **Actions** opens pin, select all, cut, copy, paste, import, and export, then **Insert tag** under Pin, undo, redo, history, voice, and style, then the keyboard, volume down, the Speak output-device volume slider, volume up, and **File Explorer**. **Import** and **Export** sit on the top row. **Insert tag** lists saved tags twelve at a time, six across. The bottom row is Prev, Next, Add, and Back. Dwell a tag to put `[tag]` at the caret. **Add** types a new tag on the keyboard. Import and Export each save the open pages, hides the other boards, leaves the main dock up, and shows the Windows open or save dialog beside the boards, with the file keyboard (`qwerty_file`). Keys type into the dialog. When the dialog closes, that keyboard closes and the previous pages return. Import replaces the boards from the chosen JSON file. Export writes an `aac-workspace` v1 file. Style is a standing ElevenLabs tag using the same names as [Voice](https://github.com/AdamRoden/Voice). The style layer lists favorites (or every style when none are starred). **Edit** opens the full list, six at a time in a 2×3 grid, with star, trash, and **Add**. A new name is typed on the keyboard and starts starred. Trashing the style in use clears it. **File Explorer** opens over Speak, switches from Actions to the keyboard, and leaves that keyboard free. Closing it restores the previous layer. The title is the open folder, with **Close**. Under that are Back, Forward, Up, the path, **List**, and **Tiles**. **Places** lists Desktop, Documents, Downloads, Pictures, Music, This PC, and disks. **List** is one row per folder or JSON file, with the name, date, type, and size. **Tiles** shows thirty-two icons at a time, eight across. A folder opens. A JSON file selects and fills the name box. Up and down arrows and the track scroll the files. The footer is the item count, the file name (typed on the keyboard), **Import**, **Merge**, and **Export**. Import, Merge, and Export ask **Yes** or **No** before reading or writing. Import replaces the board. Export writes an `aac-workspace` v1 file under that name. The volume slider has an arrow at each end. Look at the track until its ring fills. Looking at either end moves the thumb there at full speed, and a look partway moves it more slowly. List scrollbars do the same. The keyboard **Edit** key renames pins and topics. Speech boost stays on the voice list and under Settings → Speak.
- **History**: last 50 composed utterances; replay, restore, or delete.
- Settings → **Speak**: **Edit** opens the key board. **Paste** fills it from the clipboard. **Create key** clears the clipboard, closes Settings, opens ElevenLabs, and shows **Click** and **Cancel** above the taskbar at the menu’s width, with **Click** on the left. **Click** is a left click at gaze, so you can press Authorize in the browser. When that click leaves an `sk_` key on the clipboard, Gazer checks it and, if the key is valid, returns to Speak settings. **Cancel** returns to Speak settings. On the key board, **Clear** deletes the stored key. **Save** stores a valid key, or an empty key, and closes the board. The key is never stored in `settings.json`. The page also has model, speed, pitch, boost, and word predictions. Playback devices are full-height rows; scroll the page to reach them. The voice list can search by name and filter by any language. Pitch is ElevenLabs only. **System default** follows Windows. A named device is used for SAPI, v4 Turbo, saved clips, and the volume controls. If that device is unplugged, speech and volume use the Windows default until it returns.

While the action’s **source page** is `compose` (or a compose live board), `Send` and mapping/modifier commands are captured into the phrase: letters insert, `backspace` deletes, `space` inserts a space, `enter` speaks, `escape` stops speech or closes. `leftShift` / `tab` / arrows are consumed with no OS inject. Caps uses XML `ShowLayers`. The full QWERTY board (`qwerty_main`) still types into Windows. Capture table: [Actions — Composer capture](reference/actions.md#composer-capture).

Composer commands (`compose.*`, `speech.*`, `soundboard.*`, `history.*`) are in the [command catalog](reference/commands.md). Word chips use `<Phase>`: first dwell moves the caret (`compose.moveEndOfWord.<i>`), a later dwell deletes (`compose.removeWord.<i>`). When the row is paging, those two chips run `compose.pageChips.-5` and `compose.pageChips.5`.
